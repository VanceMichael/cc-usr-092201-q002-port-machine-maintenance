# 状态流转与业务规则

## 案卷状态机

```
运行中
  │ alarm_raised（原文须含 code/message）
  ▼
已告警 ────────────────► 诊断中（triage_classified：三选一成因）
  │ triage：仅维护主管             │
  ▼                                 ▼
（可开授权诊断会话取证）       检修中（work_order_opened）
                                   │  换件/校准/回退/旁路（各自签署）
                                   ▼
                                待复测（retest pass）
                                   │  retest fail → 回到检修中
                                   ▼
                    release_rejected ──► 留在待复测（记录全部缺口）
                                   │ 闸门全绿 + 独立复核
                                   ▼
                                已放行
```

## 关键规则

### 分诊（先判断再动手）
- 仅维护主管可分诊；成因限定：`机械故障 / 校准漂移 / 未确认软件参数`。
- 方案 `applies_cause` 必须与分诊一致，错配方案不能开工。
- 未分诊不能开工单。

### 授权诊断会话
- 必须声明取用目的与数据类别白名单；令牌 HMAC 签名、带 TTL（默认 30 分钟）。
- 每次 `access_diagnostic_data` 记录会话、范围、目的，独立成事件。
- 越权范围、过期、关闭后、伪造令牌一律拒绝。
- 诊断本身不改设备状态。

### 并行检修
- 工单锁：`machine:<id>` + 每个 `slot:<id>:<slot>` + 调用方附加锁。
- 两个活动工单锁集合有交集 → `ConflictError`；不交集（不同设备）允许同窗口并行。
- 同一案卷同时只有一个活动工单。
- 开工/换件/回退/旁路必须处于停机窗口内（方案标记紧急豁免除外）。

### 签署动作
- 每个动作校验：人员角色、凭证在**动作发生时间**有效、动作在凭证授权内、
  工具在凭证 `allowed_tools` 内。
- 换件额外要求：备件已为本工单 `reserved`、型号与方案一致、批次未命中召回。
- 参数回退：恢复上一版参数集并自动置为 confirmed。
- 旁路：同一案卷同时仅一条生效旁路；到期未解除升级挂起；放行前必须解除。

### 离线补录
- `occurred_at`（实际发生）与 `recorded_at`（系统接收）双时间戳入链。
- 实际时间不得晚于接收时间；补录限 72 小时内（基线历史导入走 `historical` 通道）。
- 补录动作同样要在窗口内、同样校验资质（以实际发生时间为准）。

### 召回联动
- 召回 = `part_no` + 批次清单。
- 备件入库后命中：禁止装机、禁止预留。
- 在装件命中：设备立即出现召回挂起，自动能力暂停，ETR 置为"待定（等待部件处置）"。
- 处置路径：取消工单（释放预留件）→ 换非召回批次 → 校准 → 复测 → 放行。

### 调度读模型
对每台设备输出：流程状态、开放报警、挂起原因明细、`available_caps`、
`etr`（ISO 时间或 null）与 `etr_basis`（人类可读依据）。
ETR 不臆造：在窗口内按工单剩余工时估算；无窗口则指向下一窗口起点；
命中召回或无任何窗口时返回 null 并说明原因。
