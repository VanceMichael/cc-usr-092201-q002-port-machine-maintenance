# 自动化港机维护授权

整理自动化港机配置、报警、检修和能力放行资料。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。当前记录类型包括设备配置、报警事件、诊断会话、检修方案、备件流转、放行结论，状态示例为运行中 → 已告警 → 诊断中 → 检修中 → 待复测 → 已放行。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

已整理的业务事实：

- 智慧港口依赖自动化起重机和智能车辆
- 多数设备由远程操控室运行
- 设备故障会直接影响港口作业连续性

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态和事实说明。后续服务应继续兼容这份公开资料约定。
